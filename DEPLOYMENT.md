# Deployment

## Preview locally
Open `index.html` in a modern browser. The page is static and does not require a build step or server.

## Publish
Upload the contents of this folder to the document root of a static host or web hosting account. Keep `index.html`, `style.css`, and `script.js` together.

## Customize
- Edit `index.html` to update copy, menu destinations, and project listings.
- Edit `style.css` to change the visual theme.
- Edit `script.js` for small interactive behaviors.
- Update `README.md` with actual repository links and per-project license details before public release.

The official parent-brand link currently points to https://johnlcstudios.kesug.com.
